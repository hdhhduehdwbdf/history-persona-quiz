# 古题版 24 道情景题 · 设计稿（已上线）

> 2026-10-11：本方案已落地至 `core.js`（`QUESTIONS`），旧版现代情景题保留为 `QUESTIONS_LEGACY` 作对照。
> 题目框架：六大模块 × 每模块 4 题 = 24 题，古代历史背景 + 大白话选项。

## 一、选项设计核心规则（最关键特点）

每题固定 4 个选项，每个选项绑定固定的人格能力维度：

| 维度 | 行为特征 |
|------|----------|
| 经营 | 优先搭规则、流程、账册、分账机制、复核制度，从制度层面解决长期问题 |
| 洞察 | 优先调研、核实信息、摸清各方真实情况与底层利害，先收集事实再决策 |
| 表达 | 优先讲清证据、陈述事实、解释差异，把信息传递清楚 |
| 独立 | 守住底线与原则，不因人情权势改变标准 |
| 担当 | 主动扛下责任、承担后果、主动补偿 |
| 共情 | 优先考虑他人处境、弱势群体的需求 |
| 决断 | 直接定边界、定分配方案、下达安排 |
| 开创 | 尝试新方案、新路径，做新尝试 |

**本质：不是测历史知识，测的是行为决策偏好。** 每个选择给对应维度加分，最终汇总八维向量，与人物库的历史人物能力向量做曼哈顿距离匹配。

## 二、语言规则（解决"拗口"问题）

1. **外壳古代，语言现代**：古代感只靠题干的人物身份与场景营造（"你是守城的将军"），选项措辞完全口语化；
2. 每条选项 ≤ 20 字，一句话说完，动词开头；
3. 选项中**零成语、零典故、零文言词**（"清野""力陈""虚与委蛇"等全部禁用）；
4. 每题读题 ≤ 10 秒；
5. 验收标准：不读历史书的人一遍读懂，哪条需要解释就重写哪条。

## 三、题目共性（设计权衡）

1. 题干结构统一：遇到矛盾 / 危机，问"你的第一个动作是什么"，强调**第一步动作**；
2. 场景均为冲突类：资源不足、利益冲突、上下级矛盾、法规与人情冲突、敌我博弈；
3. 选项句式刻意保持一致——**这是特性不是缺陷**：句式一致保证用户按行为偏好作答而非按语言风格作答；场景差异化由六大模块 × 六类古代身份承担；
4. 无标准答案：性格向量打分，八维能力向量 × 人物库匹配；
5. 产品定位：趣味心理测评，现代管理决策思维套古代故事外壳——**这是设计目标**。

## 四、六大模块与 24 题

### 模块一 · 行动与变化

1. 守城将军，敌军兵临城下（出击 / 守城 / 摸底 / 安民）
2. 新政推行受阻（强推 / 试点 / 争取支持 / 观望）
3. 乘胜追击 vs 粮草不济（追 / 收 / 两手准备 / 回朝请功）
4. 改革过半阻力增大（清除首阻 / 私下化解 / 折中修订 / 请旨定夺）

### 模块二 · 价值与人生

5. 功成名就后（退隐 / 再进一步 / 培养后人 / 著书传世）
6. 家族反对你认定的事（先国后家 / 先安家 / 说服同行 / 表面答应）
7. 旧友高居宰相（叙旧 / 不攀附 / 请指点 / 顺其自然）
8. 理想的一生（大事业 / 传世作品 / 受人爱戴 / 自由自在）

### 模块三 · 思考与表达

9. 朝堂被反驳（当场辩 / 会后书面 / 先扬后引 / 事后私谈）
10. 下属方案有漏洞（直接指出 / 私下提醒 / 引导自悟 / 让结果说话）
11. 说服固执的领导（算利害 / 讲故事 / 联合进言 / 等时机）
12. 被当众讥讽（回击 / 结果证明 / 幽默化解 / 分析原因）

### 模块四 · 边界与担当

13. 爱将犯错但功大（按律 / 相抵 / 戴罪立功 / 主动担责）
14. 上级决策有误（死谏 / 委婉 / 执行中纠正 / 坚决执行）
15. 机密泄露（彻查 / 引出内鬼 / 换方案 / 公开说明）
16. 朋友求办违规之事（拒绝 / 降影响 / 划底线 / 随机应变）

### 模块五 · 长期经营

17. 接手烂摊子（立规矩 / 摸底细 / 先出成绩 / 安人心）
18. 资源只够一个方向（全押 / 分散 / 借力 / 做透眼前）
19. 十年大项目 vs 一年小项目（押大 / 保命 / 各半 / 观变）
20. 有污点的人才（大胆用 / 试用 / 用长防短 / 不用）

### 模块六 · 判断与洞察

21. 流言四起（公开辟谣 / 查造谣者 / 反用作局 / 不理会）
22. 强敌来谈合作疑有诈（摸底 / 拒绝 / 留一手 / 借势）
23. 局势不明众人劝撤（坚持 / 等三天 / 两手准备 / 集体分析）
24. 天降良机（马上拿 / 查来路 / 分步接 / 不要）
