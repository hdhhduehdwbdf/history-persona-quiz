## 4. 当前产品基线（已上线，〔已查证〕）

### 4.1 产品形态

| 项 | 现状 |
|----|------|
| 技术形态 | 零构建纯前端（HTML + JS + CSS），无框架、无后端、零外部依赖 |
| 商业模式 | **完全免费**（`core.js` 的 `FREE_MODE = true` 一行开关可切回 0.99 元付费形态） |
| 题库 | 24 道情景题，每选项含八维权重 |
| 人物库 | **20 位中外历史人物**（中国 10 位 + 国外 10 位），每人 15 个完整字段 |
| 页面链路 | index → landing（首页）→ quiz（答题）→ result（结果）→ report（报告）→ share（分享卡片） |
| 部署 | CloudStudio 公网链接，「改完即上线」约定（2026-09-30 确认） |
| 代码托管 | GitHub 私有仓库 `hdhhduehdwbdf/history-persona-quiz`（2026-10-01 推送） |

- **国外 10 位**：秦始皇、李世民、成吉思汗、孔子、岳飞、达·芬奇、拿破仑、丘吉尔、爱因斯坦、莎士比亚

### 4.3 人物数据字段（每人 15 项）

`id` / `name` / `dynasty` / `tags` / `scores`（八维基准分 0-100）/ `quote`（金句）/
`opener`（梗化开场白）/ `intro` / `self_portrait` / `base_color`（三层底色）/
`interaction` / `blind_spot` / `risk` / `suggestion`（成长建议）/ `summary3`（三句话人物概括）

### 4.4 匹配引擎（当前实现）

```text
1. 八维得分：24 题选项权重求和 → raw[d]；
   scores[d] = clamp(round(32 + raw[d] × 2.3), 25, 97)
2. 距离：与每位人物的八维基准分逐维取绝对差，取平均
   mad = Σ|user[d] − figure[d]| / 8
3. 相似度：pct = round(100 − mad × 1.6) + jitter
   jitter = (答案选项序号总和 mod 7) − 3，确定性扰动，保证同答案可复现
4. 取 pct 最高者为匹配人物；matchPct 限幅 [55, 99]
```

> **与 V2.0-draft1 的差异**：原规划的"八维切档 1-5 档 + 档位串 + 兜底结局"方案
> **未采用**。实际落地为连续分 + 曼哈顿平均距离（k=1.6，经 1 万次随机作答模拟校准），
> 已解决 V1 余弦引擎"人人 90%+"的问题：当前随机作答相似度中位数约 74%，
> 95 分位约 78%〔已查证，模拟数据〕。
> 已知残留：极端档人物（如共情 32 的秦始皇）在纯随机作答下命中率低，
> 根治需档位化引擎，见 §7 迭代方向。

### 4.5 报告结构（七章 + 首屏两模块）

| 序 | 模块 | 内容 |
|----|------|------|
| 0 | 人物概括 · 三句话读你 | `summary3`，每人物逐条手写，非模板拼装 |
| 0 | 梗化开场白 | `opener`，第一人称毒舌向（详见 5.1） |
| 一 | 人物匹配详情 | 匹配人物介绍 + 匹配度 |
| 二 | 八维能力雷达图 | canvas 本地绘制，用户 vs 人物双多边形 |
| 三 | 人物自画像 | `self_portrait` |
| 四 | 共同底色拆解 | `base_color` 三层 |
| 五 | 现实互动方式 | `interaction` |
| 六 | 盲点与风险提醒 | `blind_spot` + `risk` |
| 七 | 成长建议 | `suggestion` + 两个待激活维度 |

加载动画：五步趣味文案（"调阅作答底档 / 请本人出场过目档案"式），标题「正在为你分析」（全站无「AI」字样）。

### 4.6 视觉身份（定稿禁区）

**暖纸底（#FAF6EF）+ 朱红印章（#B03A2E）+ 赭金点缀（#A88132）+ 圆角卡片。**
出处是宣纸/印泥/题批，为题材服务。2026-09-30 曾按"去 AI 生成感"清单改版为靛青方案，
用户判定更丑，已完整回退——**结论：题材出处的选择 > 清单式规避，配色不再动。**
详见 `设计思路.md`。

### 4.7 首页（landing）内容基线

- 主标题「历史人物性格匹配测评」+ 一句话说明（24 道情景题匹配历史人物）；
- **无「测评说明」板块**（2026-09-30 应用户要求删除，该页用于对外介绍）；
- 人物谱系表述：横跨古今中外、持续扩充，**不写具体数量**；
- 印章墙 6 枚示意；一行极简合规说明（趣味测评、数据仅本地处理）；
- 免费表述为正式口径：「当前开放使用，无需付费」，无促销话术、无价格数字。

## 5. 已落地的 V2.0-draft1 规划项（保留有效部分）

### 5.1 梗化开场白〔已上线，从 P0 规划变为全量实现〕

- 20 位人物每人一条第一人称开场白（`opener` 字段），超出原规划的 12 条；
- 露出位置：**结果页首屏**（"他翻完你的档案，开口第一句——"）+ **报告页首屏**；
- 文案风格：损中带准、人物口吻、无 AI 腔（原规划原则保留）。
- 示例：曾国藩「我不是聪明人，我只是把"笨"熬成了别人学不会的东西。」、
  达·芬奇「我笔记里躺着七千页没写完的点子——你收藏夹里那些"稍后读"，我认了。」

### 5.2 文案与工程修复〔已上线〕

- 加载文案「AI 正在生成」→「正在为你分析」，全站零「AI」残留；
- 底栏遮挡病根修复：`html,body{height:100%}` → `min-height:100%`，三页 overlap = 0；
- 报告加载五步改为轻趣味文案。

## 7. 迭代方向（更新后的待办优先级）

- **P1 · 匹配引擎 v2 完全体**：档位化（1-5 档）+ 兜底结局，解决极端档人物命中率
  （当前随机作答下部分人物难以命中的残留问题）；
- **P1 · 二维码真实化**：分享卡片二维码替换为部署地址的真实可扫静态链接，或移除区块；
- **P2 · 彩蛋机制**：触发题 + 隐藏人物 + 兜底（原 5.3 方案可复用）；
- **P2 · 人物库扩充**：20 位基础上扩充（首页已预留"持续扩充"表述，无数量承诺）；
- **P2 · 基准分校准**：收集"结果准不准"反馈，众数回流修正人工基准分。

## 9. 成功指标（上线后观察）

| 指标 | 定义 | 目标 |
|------|------|------|
| 分享率 | 打开分享卡片人数 / 完成测评人数 | ≥ 25%〔推测，假设值〕 |
| 相似度分布 | 随机作答中位数 | 55%-80%（当前 ~74%，达标〔已查证〕） |
| 人物命中率均衡度 | 20 位人物在随机作答下均可达 | 当前未达标（极端档人物难命中），引擎 v2 目标 |
| 二周目率 | 同一用户重复完整作答 | 观察项，无埋点则人工收集反馈 |

## 10. 明确不做的事（本期边界）

- 不做账号体系、不做后端存储；
- 不动视觉令牌与印章（设计思路.md 禁区）；
- 不做 8 维以上的维度扩张；
- 不把相似度百分比"美化"回 90%+；
- 首页不出现促销话术与具体人物数量。
