## 🎯 这是什么

「历史人物测验」是一个纯前端性格测评应用：回答 24 道古风情景题，系统会把你压缩成**八维人格向量**，与历史人物库的基准画像做曼哈顿距离匹配，找出与你性格最接近的那一位——并生成**七章深度报告**与**可保存的分享卡片**。

- 🀄 **人物选取参照王者荣耀英雄对应的历史原型**，普通用户认知零门槛
- 📜 **古题版题库**：24 道题分六大模块（行动与变化 / 价值与人生 / 思考与表达 / 边界与担当 / 长期经营 / 判断与洞察），每模块 4 题
- 👫 **女性优先 / 男性优先 / 不限**，三种候选池任选
- 📊 每位人物 15 个完整字段：八维基准分、金句、梗化开场白、人格解读、盲点、风险提示、成长建议、三句话概括
- 🎨 「宣纸 + 朱红印章」视觉体系，Canvas 手绘分享卡片（3:4 / 1:1 双比例）

| 维度 | 考察什么 |
|---|---|
| 决断 | 拍板速度与担当 |
| 共情 | 接住他人情绪的能力 |
| 开创 | 对新机会的胃口 |
| 洞察 | 看人看事的深度 |

每道题的四个选项携带不同八维权重，作答即画像。

## 🧮 匹配引擎

当前版本为**引擎 v2.0：标准化曼哈顿距离**。

```
pct = 100 − 标准化平均绝对差 × 38 + 确定性微扰
```

- **八维各自标准化后再比较**：用户侧按题库解析推导的均值/标准差归一化，人物侧按候选池归一化，两侧量纲对齐 → 八个维度天然等权，题目供能多寡不再影响公平性
- 系数 `K = 38` 经 **5 万次随机作答模拟校准**（中位数 76%，95 分位 85%，min 55 / max 97）
- **全部人物均可被命中**（改造前只有少数人物可达、单个人物占比高达 42%）；命中分布熵 4.48 bit，接近均匀上限 4.81 bit，既有区分度又不失衡
- 改题库后标准化参数自动跟随，无需人工重调常数
- 匹配区间收敛在 55–99，最高分人物即你的「历史人格镜像」
- 旧版余弦相似度方案因「人人 99%」已废弃
