# 你最像哪个历史人物 · 历史人物性格匹配测评

一个**零构建、零依赖**的纯前端性格测评应用：选择男生版或女生版，回答 24 道情景题，通过八维人格模型与曼哈顿距离匹配引擎，从对应性别的人物池中找出与你性格最接近的历史人物，并生成可分享的个性化报告与分享卡片。

> 已公网上线，全功能免费开放。商业模式（付费解锁 / 免费模式）由一个开关变量控制，一行即可切换。

---

## ✨ 产品亮点

- **原创八维人格模型**：决断、共情、开创、洞察、表达、经营、独立、担当——八个维度覆盖决策风格、人际模式、压力应对与自我认知，而非照搬 MBTI 或大五人格。
- **24 道情景式题目**：全部为贴近真实生活的两难情景（职场危机、人际冲突、重大抉择），每道题的四个选项各自携带不同的八维权重，作答过程即是一次自我审视。
- **27 位历史人物库（元数据标签化 + 王者荣耀同款阵容）**：全部人物带 gender（男/女）与 region（中国/国外）双元数据标签，人物选取参照王者荣耀英雄对应的历史人物，普通用户认知零门槛。女生版 10 位全部为中国人（武则天、李清照、上官婉儿、王昭君、花木兰、芈月、蔡文姬、孙尚香、虞姬、甄姬），男生版 17 位含中外名家。每位人物包含 **15 个完整字段**：八维基准分、金句、梗化开场白、人物简介、自画像、盲点、风险提示、成长建议、三句话人物概括等。
- **性别版本选择**：测评开始前先选择男生版 / 女生版，匹配引擎只在对应性别的人物池中计算，结果更贴合。
- **专业级报告体系**：结果页给出匹配度、八维雷达图与「三句话读你」；报告页以七章结构逐层展开，内容逐人物人工撰写，不是模板拼接。
- **Canvas 手绘分享卡片**：支持 3:4 与 1:1 两种比例，含雷达图、印章、纹饰与人物专属配色，可直接保存用于社交分享。
- **经过校准的匹配算法**：匹配度分布经 10,000 次随机作答模拟校准（中位数 74%、95 分位 78%），避免「人人 99%」的敷衍结果。

## 🎯 页面流程

```
index.html → pages/landing.html（首页）
           → pages/gender.html（男生版 / 女生版选择）
           → pages/quiz.html（24 题答题）
           → pages/result.html（匹配结果 + 雷达图 + 三句话概括）
           → pages/report.html（七章完整报告）
           → pages/share.html（分享卡片生成，3:4 / 1:1 双比例）
```

答题进度与结果保存在浏览器本地（localStorage），刷新不丢失，可随时回退重答。

## 🧮 匹配引擎

当前版本为 **引擎 v1.1：八维曼哈顿距离**。

```
pct = 100 − 八维平均绝对差 × 1.6 + 确定性微扰
```

- 系数 k = 1.6 通过 10,000 次随机作答模拟校准，使匹配度分布自然、有区分度；
- 匹配区间收敛在 55–99，最高分人物即为你的「历史人格镜像」；
- 前一版采用余弦相似度 + 全正向量，实测导致所有人物匹配度普遍 90%+，已废弃。

## 🏗️ 技术架构

| 层 | 实现 |
|----|------|
| 形态 | 纯静态站：HTML + CSS + 原生 JavaScript，无框架、无构建工具、无外部依赖 |

| 无障碍 | 键盘焦点可见（:focus-visible）、prefers-reduced-motion 弱动效适配 |
| 部署 | 静态托管，改完即上线 |

## 🎨 设计原则

- **有出处的视觉身份**：配色取自宣纸、印泥与题批——朱红印章是全站唯一的记忆点，不做多色扩散；
- **内容优先**：报告内容按真实序数组织（七章结构），拒绝凑数式板块；
- **克制的动效**：仅保留轻量淡入，并为偏好减弱动效的用户自动关闭。
